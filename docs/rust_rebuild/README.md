# docs/rust_rebuild

本目录记录 `rust_standalone_alpha1` 上 Rust 重构的计划与已合并 PR。只改这里，不改代码、`evidence/`、`review/` 或其他文档。

| 文件 | 内容 |
|---|---|
| [PLAN.md](PLAN.md) | 阶段、门禁、决议 |
| [PR_LOG.md](PR_LOG.md) | `b243fa00` 之后 first-parent 主线上的已合并 PR |
| `prs/PR-<n>.md` | 单个 PR 的详情 |

证据类 draft PR 只在正文里引用，不进入 `PR_LOG` 表。未合并的 PR 不要写成已合并。

每次再有 PR 合入 `rust_standalone_alpha1`，在同一 PR 或紧随的文档 PR 中更新 `PR_LOG.md`，并新增或更新 `prs/PR-<n>.md`。
