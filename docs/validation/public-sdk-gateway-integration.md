`modules.js` installs POST `/api/modules/staffdeck-sdk/call` with `{operation,input,scope}`. Scope is exactly `{kind:'agent',agentId:<selected employee>}` or `{kind:'team'}`. Every agent/team operation requires scope; there is no configured-target fallback or legacy input.agentId selection. The four global APIJob operations (`get_job/get_job_result/job_events/cancel_job`) omit scope and use the original job ID. The SDK client receives selection through call options `{scope,signal}`; the browser client/Host owner must update its production mapping to this wire contract.

The route grant is exactly the owner's 32-name `PUBLIC_APPROVED_OPERATIONS` table, not a browser-supplied grant, path or URL. The SDK helper's default remains `[]`. Each request verifies the configured PilotDeck user, real SD actor/tenant, active owned account credential and per-operation scope before business fetch. Resource selection never changes this identity. The account credential requirement also excludes employee keys from team facade calls. SD enforces the selected staff's original viewer/manager/branch policy.

Team is limited to the four catalogs `list_tools/list_general_skills/list_knowledge_bases/list_sops` and five transient preview operations (generate/rewrite/status/events/cancel). The SDK maps these to the fixed `team/...` facade, which retains original native `agent_id=None`. All other team operations return `PUBLIC_TEAM_PROTOCOL_UNAVAILABLE` before business transport, with no substitution of target or overall agent. Missing/invalid scope and old input.agentId selection return explicit 400 errors. Conditional SDK requests using If-Match or input etag/ifMatch/if_match are explicitly 409 BLOCKED until the conditional-write contract exists; no ETag is silently omitted to enable a write.

GET `/api/modules/staffdeck-sdk/events` permits only `job_events` and `preview_job_events`, with jobId. APIJob events omit scope: Last-Event-ID header wins over query lastEventId. Preview events use query `scope=agent&agentId=<selected>` or `scope=team`, with optional afterSeq mapping only to SD after_seq. Team+agentId and agentId without explicit scope are rejected. The original bytes, event names, ids and data.seq are passed with backpressure; no sequence/id conversion, synthesized events or reconnect. Preview create/rewrite remains the facade's real 202 transient job with dirty current_skill/conversation/target fields intact and no draft create/save.
